# TOP · 双五轴镜像测厚闭环系统

> **一句话定位**：面向薄壁件加工与在线检测，把“超声测厚·电涡流法向·压力/W轴·水压质量门·线激光点云”五类传感接到同一条受约束补偿链路上，在真实工业设备上跑通测量—估计—控制—安全闭环。角色为系统研发工程师，覆盖坐标/运动学、传感器链路、状态估计、补偿控制、64B 协议与 C++/Qt 上位机联调。

**硬指标（对外口径，软件链）**：五轴补偿效果 **±0.05 mm** / 测厚软件精度 **±0.01 mm**。团队与上游能力按边界表述，不归为个人成果；仿真结果注明为冻结模型仿真。

## 3 个关键技术决策

### 1) 坐标与运动学 — 先统一系，再谈补偿

- **问题**：工件/设备/TCP/传感器多系并存 + 安装偏置，姿态误差会直接错位补偿点。
- **选择**：统一到设备/补偿坐标；FK/IK 按实际轴序与偏置解析 `X/Y/Z/A/C`；RTCP 保持刀尖点；线激光经标定反投影为点云后统一系内拟合。
- **工程重点**：周期角等价解、`atan2` 象限、跨 ±180° 连续、按上一拍选最近解、不可达与限位（含约 ±370° 保护）。
- **证据**：[设备模拟](media/top/device-simulation.mp4) / [五轴镜像控制](media/top/five-axis-control.mp4) / [双五轴布局](media/top/13_dual_head_axis_layout.png)

### 2) 感知—估计 — 保证“这一拍可信”再滤波

- **问题**：滤波器总能输出数字，但回波/耦合/超时异常时不能继续用旧补偿。
- **选择**：A 扫回波质量门 + 水压耦合门 + 超时/突变门前置；通过后再进一维 Kalman（预测—协方差—增益—`Q/R` 融合）与创新残差门。
- **边界**：更平滑不等于更高精度；无效/缺测必须在补偿前阻断。
- **证据**：[超声回波波形](media/top/09_ultrasonic_wave_filtered_stable.jpg) / [TP500 回波标注](media/top/tp500-waveform.png) / [融合结构](media/top/eddy-ultrasonic-fusion.png) / [厚度轨迹](media/top/thickness-trace.png)

### 3) 控制与安全 — 受约束补偿链

- **问题**：厚度误差直通执行会导致超调、振荡或过切。
- **选择**：`误差 → 死区 → 参数渐入 → 变速积分 → 增量式 PID → 单步限幅 → 总补偿限幅 → 执行`，异常进保持/降速/抬刀状态机；覆盖 W1 抬刀、补偿初始化、板卡报警、最大下刀限制、抗饱和与迟滞。
- **证据**：[W1/DW2 曲线](media/top/15_w1_dw2_thickness_curve.png) / [厚度-进给曲线](media/top/thickness-vs-feed.png)

## 通信与软件（可复现要点）

- **64B 固定协议**：`2B header + 62B body` 累计接收，处理 TCP 拆包/粘包与跨 `recv` 缓存；字段偏移/大小端/定点编码明确，当前生产协议无 CRC（与通用协议分开表述）。
- **C++/Qt 分层**：采集（DPL 板卡 A 扫 + 时间戳/序号/质量）→ 协议 → 估计 → 控制 → 显示/日志（按程序名 CSV）。
- **软实时**：`QThread + Worker + moveToThread + QueuedConnection`；以周期分布与 `P95/P99` 长尾度量，非仅均值。
