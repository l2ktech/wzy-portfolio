这是一个面向薄壁件加工与在线检测场景的**双五轴在线测厚与多传感闭环控制系统**。系统两侧机构隔着薄壁工件协同运动：加工/测量侧负责姿态与测厚，支撑侧负责跟随和接触力控制，同时结合超声、电涡流、压力、水压和线激光等信息，把测量结果转换成受约束的补偿量反馈给设备。

项目角色为**系统研发工程师**，工作覆盖跨模块联调、软件开发与算法分析：坐标变换、运动学、传感器链路、状态估计、补偿控制，以及通信协议、C++/Qt 上位机、线程时序、安全保护与问题定位。

项目主要精度指标：**五轴补偿效果 ±0.05 mm、测厚软件精度 ±0.01 mm**。

## 一页看懂系统

系统由五类感知信息围绕双五轴运动形成闭环：

- **超声回波**：主厚度测量；
- **四路电涡流**：估计探头与工件表面的相对法向；
- **轴向压力**：判断支撑头接触力是否合适；
- **水压**：判断超声耦合状态和当前测量是否可信；
- **线激光**：表面轮廓点云，用于扫描、标定、位置预估和碰撞边界。

数据不是直接把某个传感器值送给执行机构，而是经过**坐标统一 → 运动学映射 → 质量判断 → 状态估计 → 受限补偿控制 → 安全状态机**再作用到设备。

```mermaid
flowchart LR
    A["五类感知<br/>超声 · 电涡流 · 压力 · 水压 · 线激光"] --> B["坐标统一<br/>设备 / 工件 / TCP / 传感器系"]
    B --> C["运动学映射<br/>X/Y/Z/A/C · 多解连续 · RTCP"]
    C --> D["质量判断<br/>回波 / 耦合 / 超时 / 突变门"]
    D --> E["状态估计<br/>一维 Kalman"]
    E --> F["受限补偿控制<br/>死区→渐入→变速积分→增量PID→限幅"]
    F --> G["安全状态机<br/>保持 / 降速 / 抬刀"]
    G --> H["双五轴设备执行"]
    H --> A
```

超声是厚度主测量通道：A 扫回波经过波形滤波与质量门，从有效回波中确定传播时间并计算厚度，再经过一维 Kalman 平滑和异常门，才允许进入补偿控制。关键不是公式，而是保证"这一拍厚度真的可信"：回波异常、耦合异常、超时、缺测或明显突变时，不能因为滤波器还能输出一个数字，就继续使用旧补偿。

## 坐标与运动学

系统中同时存在工件、设备、末端执行器、TCP、线激光和各传感器坐标系，加上安装偏置。不同传感器看到的量必须先统一到设备/补偿坐标中，才能参与姿态和位置补偿，主要姿态落到设备 A/C 两个旋转轴上。

- **正/逆运动学**：把 CAM/目标位姿按实际轴序、方向和安装偏置解析成 X/Y/Z/A/C。工程重点是**多解与连续性处理**：周期角等价解、atan2 象限、跨 ±180° 连续、按上一拍姿态选最近解、不可达判断、机械限位与约 ±370° 保护。
- **RTCP（刀尖点保持）**：旋转轴改变姿态时同时补偿直线轴，使 TCP 相对工件保持在目标位置，把"姿态变化"和"实际测量点位置"绑定在同一条几何链里。
- **线激光扫描链**：标定相机与激光平面的几何关系 → 激光线反投影为 3D 点云 → 统一到设备坐标系 → 表面轮廓、几何拟合与补偿量。点云/曲面法向还会影响测头姿态，与刀路光顺属于同一条几何数据链。

## 感知、估计与质量判断

- **电涡流法向**：四路电涡流按约 90° 分布在测头周围（量程约 0–10 mm），不负责测厚，而是估计超声探头应该朝的方向；把四个测点拟合为平面求法向，再经坐标变换和逆运动学转换为旋转轴与直线轴的姿态补偿。
- **压力与 W 轴**：支撑侧通过应变式压力传感器测量接触力。压力太小支撑不足、振动增加，太大又可能使薄壁件变形或划伤，因此独立 **W 轴**沿支撑头轴向做小范围快速修正，把"大范围位置随动"和"局部接触力调节"分开。
- **水压质量门**：水压是超声耦合状态的代理量。水压异常时，即使当前厚度数值看起来正常也不能默认可信，需要降低可信度或阻断补偿。
- **多传感器协同**：不同传感器承担不同职责：**超声回答厚度，电涡流回答姿态，压力回答接触状态，水压回答测量质量，线激光回答轮廓与几何信息。** 先把各自物理意义和质量边界分清，再决定是否允许进入后续控制。
- **一维 Kalman 与异常门**：连续厚度估计使用一维 Kalman（状态预测、协方差传播、增益与 Q/R 观测融合），结合创新残差和质量门拒绝异常数据。工程边界：**滤波更平滑不等于测量精度自动更高**，无效值、突变、超时和缺测必须在进入补偿前被明确处理。

## 控制与安全

厚度误差进入补偿控制后经过一套工程保护：

**误差 → 死区 → 参数渐入 → 变速积分 → 增量式 PID → 单步限幅 → 总补偿限幅 → 设备执行**

异常时进入**保持、降速、抬刀**等状态。生产代码覆盖 W1 抬刀、补偿初始化、板卡报警、最大下刀限制等逻辑，以及抗积分饱和、微分滤波、死区、迟滞和限幅等保护项。调参是在上升时间、超调、稳态误差、振荡、噪声放大和系统延迟之间做折中。

除增量式 PID 外，系统还包含 **MPC 变形预测**：四路电涡流实时给出局部间隙与变形，结合支撑侧当前位速和后续一段已知加工轨迹，对未来几个控制周期的薄壁变形做滚动预测，并把速度、加速度、行程和安全间隙作为约束，提前计算支撑侧法向位置/速度修正，每周期只执行当前最优量第一步。

接触方向另用**阻抗控制与力位混合控制**：末端压力用于判断支撑头接触力是否合适，阻抗控制把位置误差映射为力，力位混合在需要力控的方向出力、需要位置控的方向保位置，避免支撑不足或过压导致薄壁件变形。

## 通信与软件

- **64 字节固定协议**：字段偏移、大小端/字节序、有符号数、定点编码、固定长度累计接收；处理 TCP 拆包、粘包和跨 recv 缓存，按 2B header + 62B body 累计完整帧。当前生产 64B 协议没有实现 CRC，和"通用协议可以有 CRC"分开描述。
- **EtherCAT 测量从站**：四路电涡流的 MCU 测量节点经 LAN9252 以 EtherCAT 从站接入系统，LAN9252 原生提供 SPI/HBI MCU 接口与 Distributed Clock，把多路电涡流法向数据送入控制环。
- **C++/Qt 上位机**：模块化分层——采集（DPL 板卡读 A 扫回波，维护时间戳/序号/质量状态）、协议（组帧解析）、估计（Kalman + 质量门）、控制（补偿映射 + 保持/降速/抬刀/防过切）、显示与日志（按程序名组织 CSV）。
- **多线程与软实时**：QThread + Worker、moveToThread、QueuedConnection；明确 Windows + Qt 是**软实时**，验证周期分布、P95/P99 长尾、CPU 占用和异常响应，而不是只看平均周期。
- **代码审查**：登记并处理了计时对象迁移到工作线程后的忙等死循环、跨线程直接调用等线程与时序风险。
